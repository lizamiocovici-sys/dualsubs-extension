# DualSubs — двойные субтитры для subtitle.love

Расширение для Яндекс.Браузера (Chromium, Manifest V3). Делает то же, что 2SUB, но на страницах subtitle.love:

1. **Перевод слова при наведении — главный сценарий.** Слова текущей реплики предзагружаются заранее, поэтому подсказка появляется сразу. При наведении видео ставится на паузу и продолжается после ухода курсора (можно отключить в настройках). Клик по слову открывает карточку с озвучкой и кнопкой «в словарь».
2. **Перевод фразы целиком.** Выделите часть реплики мышью или нажмите маленькую кнопку «Ф» на субтитре — появится перевод всей фразы.
3. Оригинал EN + перевод RU одновременно, с переключателями.
4. Панель «Диалоги» с поиском и переходом по времени.
5. Личный словарь:экспорт/импорт JSON, поиск, ручное добавление.
6. Ручная загрузка своих `.srt` / `.vtt`, если дорожки не нашлись.
7. Настройки внешнего вида и горячие клавиши.

## Как работает

На странице subtitle.love видео живёт в iframe стороннего плеера (`gencit.info`, `allo.cdnlbox.club`, `api.embf.net`). Расширение внедряется и туда, и туда:

- у `gencit.info` читает `window.playerData.config.cc` — там могут быть `en_*.vtt`, `ru_*.vtt` и `ua_*.vtt`; расширение берёт только EN и RU, а украинскую дорожку и родные субтитры плеера принудительно выключает;
- у `api.embf.net` разбирает массив `cc` с именами «Eng. full» / «Рус. полные»;
- у `allo.cdnlbox.club` и в остальных случаях читает реплики из самих текстовых дорожек `<video>` (`textTracks` / `remoteTextTracks`), поэтому все три плеера работают одинаково;
- если русской дорожки нет, перевод получает через публичный API и кэширует локально;
- сопоставление EN/RU идёт по времени пересечения реплик.

Данные не отправляются на сервер автора расширения. Словарь и настройки лежат в `chrome.storage.local`, кэш переводов — там же.

Расширение активируется только на страницах `subtitle.love` и в их iframe-плеерах. На других сайтах (например, GitHub) оно не вмешивается в страницу.

## Установка в Яндекс.Браузере

1. Откройте `yandex://extensions` (или `chrome://extensions`).
2. Включите **«Режим разработчика»** в правом верхнем углу.
3. Нажмите **«Загрузить распакованное расширение»**.
4. Выберите папку `dualsubs-extension` (внутри должен лежать `manifest.json`).
5. Убедитесь, что расширение включено и нет красной ошибки «Ошибка манифеста».

Если в Яндексе пункт «Загрузить распакованное расширение» не виден, откройте `chrome://extensions` — Яндекс.Браузер понимает этот адрес.Расширение можно временно проверить в Chrome: код у них общий.

Если браузер просит разрешения для дополнительных плееров, подтвердите — они нужны, чтобы перехватывать субтитры внутри iframe.

Расширение следит за сменой эпизода: если плеер переключает серию без перезагрузки страницы (кнопкой «дальше» внутри плеера), дорожки перечитываются автоматически.

## Быстрая проверка

1. Откройте страницу сериала на `subtitle.love` и нажмите «Смотреть».
2. В плеере включите **английские субтитры** (родные можно оставить — расширение их скроет).
3. Нажмите иконку **DualSubs** → в шапке popup должно быть зелёное `EN … · RU …`.
4. Подведите курсор к любому слову в английском тексте — должна появиться жёлтая подсказка с переводом.
   - Первые 1–2 секунды может идти предзагрузка; затем подсказка мгновенная.
5. Кликните слово → карточка с 🔊 и «＋ Слово». Добавьте слово и откройте вкладку **Словарь** — оно должно там быть.
6. Выделите мышью пару слов или нажмите «Ф» на субтитре → карточка с переводом всей фразы; кнопка «＋ В словарь» сохраняет её целиком.
7. Нажмите «Д» или `Alt+T` → панель «Диалоги»; клик по строке перематывает видео. В полноэкранном режиме панель открывается **слева внутри плеера** (в обычном режиме — справа на странице).
8. Если текст опережает звук, нажмите `−0.5 с`; если опаздывает — `+0.5 с` (или `Alt+← / Alt+→`, с Shift — по 2 с). Сдвиг сохраняется для этого эпизода.
9. Проверьте `Alt+S` (оригинал), `Alt+D` (перевод), `Alt+↑/↓` (размер), `Alt+H` (родные субтитры).

### Если подсказка не появилась

- Убедитесь, что в плеере реально включены английские субтитры — без EN-дорожки нечего размечать.
- Откройте popup → вкладка **Справка** → проверьте, что расширение загружено без ошибок.
- На странице `yandex://extensions` нажмите «Обновить» у карточки расширения и перезагрузите страницу с видео.
- Если плеер другой, загрузите свои `.srt`/`.vtt` в popup (раздел «Свои субтитры»).

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `Alt+S` | показать/скрыть оригинал |
| `Alt+D` | показать/скрыть перевод |
| `Alt+T` | панель «Диалоги» |
| `Alt+↑` / `Alt+↓` | размер текста |
| `Alt+H` | скрыть/показать родные субтитры плеера |
| `Alt+←` / `Alt+→` | сдвиг субтитров на 0.5 с |
| `Alt+Shift+←` / `Alt+Shift+→` | сдвиг субтитров на 2 с |

## Структура

| Файл | Назначение |
| --- | --- |
| `manifest.json` | разрешения и точки входа |
| `background.js` | ретрансляция между фреймами, fetch VTT, перевод с кэшем |
| `content-player.js` | поиск дорожек, субтитры, hover-перевод, словарь, диалоги |
| `content-main.js` | панель «Диалоги» на странице сайта |
| `popup.html` / `popup.js` / `popup.css` | настройки, словарь, импорт файлов |
| `player.css` / `main.css` | стили внутри iframe и на странице |

## Известные ограничения

- Перевод слов/фраз через публичный API требует интернета; без него работают только готовые RU-дорожки и уже закэшированные слова.
- Точность совпадения реплик зависит от того, как плеер разметил VTT; при расхождении используйте сдвиг в настройках или загрузите свои файлы.
- Если плеер рисует субтитры своим DOM и не отдаёт их через `textTracks`, поможет ручной импорт `.srt`/`.vtt`.
